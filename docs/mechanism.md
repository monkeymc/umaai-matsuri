## 1. 回合与阶段

- 回合范围：`turn ∈ [0, 77]`（全 78 回合）；Senior 10 月後半最终结算在 `turn 68`。
- 三次剧本结算 / 進捗発表会：`turn 24 / 48 / 68`，门槛全演目 Lv `3 / 5 / 6`
  （`single_mode_15_schedule`；`need_act_num = 5`）。
- 阶段机（内部强类型，对外 `StageId`）：当前 S1 阶段机为 `Begin → Train → End`；真实阶段需按
  合宿 / 伝受 / 発表会 / 本番 / URA 收尾拆分。❓精确阶段顺序待 S0 收口。
- 决策点：普通训练 / 演目稽古 / 休息 / 比赛；伝受分配与転成是独立选择点。❓
- 固定回合特例：第 3 回合神駒加入 + 首次伝受；Junior 夏合宿（7 月前半–8 月後半）；
  Junior / Classic 年末伝受 + 転成；Senior 10 月後半本番；本番后仍可攒 gauge / 演目稽古到 turn 78。

## 2. 资源与账本

- 剧本资源：**5 条演目ゲージ**（对应 5 训练）+ **5 个演目 Lv**。
- 入账：对应演目担当参加训练 `+1`，友情训练 `+2`；休息 / 非目标比赛最低 `+1`；
  **不随回合自然减少**。❓友情 +2 的范围、休息 / 比赛加哪一条。
- 消费：gauge 满后对应训练变演目稽古；执行后该演目 `Lv +1`、gauge 清零。
- 可延期：亮起后不必立即执行、不会过期；多个演目同时亮起可任选其一，其他不消失。
- 跨回合状态存局面字段，不存阶段枚举。

## 3. 训练与加成

- 普通训练与演目稽古是**同一训练 ID**；合宿不是第三种训练类型，只是把训练位切到演目稽古。
- 演目稽古效果：全五项属性 + SP；Lv1 已给全属性 +10 以上；Junior / Classic / Senior 三档不同；
  Lv8 后增幅很大；Lv10 为 SSR 友人上限。❓逐级数值。
- 教え加成作用于「演目担当」（含编成外神駒 / 编成外支援角色），不是全体人头；
  羁绊教え只对编成支援卡生效。
- 失败率：不屈教え按剩余体力降低；Lv10 时体力无关、失败率 -100%（Lv9 需体力 ≥5）。
- 羁绊 / 红点 / 训练后处理：暂按引擎默认档，剧本覆写点待 S4/S5 确认。

## 4. 比赛与赛程

- 赛程：各马娘固有目标赛事 + URA 决赛收尾；Senior 10 月後半本番为剧本最终结算，不是育成结束。
- 合宿期间有目标比赛则合宿延长：**不产生额外回合**，把后续正常回合改标为合宿回合。
  ❓延长量按场次还是固定 1 回合。
- 比赛倍率 / PT 折算：❓本剧本未确认是否有剧本专属倍率，勿套用温泉 / 拉面口径。

## 5. 事件

- 固定事件：第 3 回合神駒加入 + 首次伝受（羁绊 / 得意 / 灵感 / 助力 / 体力）；
  Junior 年末 / Classic 年末伝受 + 転成；Senior 9 月前半各链接角色事件；Senior 10 月後半本番。
- 伝受：每次把 5 个教导各分配到一个演目；合宿前与進捗発表会时可重排，其余约半年固定。
- 転成：初始 5 种教え之一作材料，强化新教え并附加転成效果；初始之间 / 新教え之间不可互转；
  每个初始教え只能用一次；组合确定后不可改。❓転成后是否完整保留基础效果。
- 大成功 / 成功奖励：友情 bonus / 得意率 / hint 率 / 赛道 bonus；❓具体数值与未达标惩罚。
- 特殊事件「追加稽古」：属性 +20 且加 gauge；❓触发率、gauge 增量。

## 7. 随机轴与可复现

- 局面流 / 事件流：由 `BaseGame` 持有，每回合按 `(master, turn)` 派生。
- 策略流：本局面自持，动作结算与剧本机制随机从它取；`set_rule_master` 与回合边界重置。
- 决策流：只给 `Trainer`，不影响结算随机。
- `fork_for_rollout`：克隆 + 注入 rollout 主种子；任何不由传入 rng 驱动的流必须在这里重置。
